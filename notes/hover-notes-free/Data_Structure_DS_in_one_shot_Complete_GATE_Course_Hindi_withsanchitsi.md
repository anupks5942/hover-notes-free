### [14:02] Four Fundamental Specifications of Data Structures

* [14:02–14:11] The instructor states that understanding any data structure requires knowing how data is organized within it, calling this a very fundamental requirement.

* [14:32–14:59] The instructor highlights **accessing methods** as the second important property, emphasizing that any data structure cannot be accessed arbitrarily in any manner:

    * Single level is involved.

    * Implementation is relatively complex in comparison to linear data structures.
    * Data elements cannot be traversed in a single run only.
    * Examples: trees and graphs.

* [39:01–39:08] The instructor explains that once an array's size is declared, the operating system cannot reclaim or reuse any empty, unused space left inside that allocated block. This type of wastage is known as **internal fragmentation** because the unused space is located inside the assigned location.
